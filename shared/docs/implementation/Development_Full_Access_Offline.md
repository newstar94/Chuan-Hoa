# Development Full Access offline

This channel is for the application author and QA only. It does not remove
license validation: the signed Development lease remains bound to the device
thumbprint and exact client release. It does not require an end-user login.

The Development bootstrap lease contains FORMAT_SCAN, SPELLING_SCAN,
DOCUMENT_TOOLS, AUTOFIX, TABLE_IMAGE_TOOLS and FULL_ACCESS. Production users
must use the production identity and entitlement flow.
