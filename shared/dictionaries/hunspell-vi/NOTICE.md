# Vietnamese spelling lexicon notice

The `vi-DauCu.dic` and `vi-DauMoi.dic` files are copied from
[`1ec5/hunspell-vi`](https://github.com/1ec5/hunspell-vi), commit
`39cc647f0cf3bdfc579980a2c3aac3f6f4203fe6`.

They are used as separately identifiable spelling data. The upstream dictionary
is licensed under GNU GPL version 3. The Vietnamese license notice supplied by
the upstream project is preserved as `LICENSES-vi.txt` in this directory.

The Chuẩn hóa code does not copy or link the Hunspell engine. It parses the word
entries and distributes them inside the signed, temporary rule pack.
